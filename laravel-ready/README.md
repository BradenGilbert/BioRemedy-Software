# Laravel CRM Schema Conversion

This folder converts the SQL files in `crm-schema` into Laravel-ready migrations and Eloquent models.

## Where these files go in a Laravel app

- `database/migrations/*.php` -> `database/migrations/`
- `app/Models/*.php` -> `app/Models/`
- `app/Filament/Resources/*` -> `app/Filament/Resources/`

## Filament admin

The `app/Filament/Resources` folder contains Filament v3-style simple resources for the CRM foundation.

Each resource uses:

- `Filament\Forms\Form`
- `Filament\Tables\Table`
- `->schema([...])` for forms
- `->actions([...])` for row actions
- `->bulkActions([...])` for bulk table actions
- one `ManageRecords` page per resource for modal create/edit flows

Included resources:

- Accounts
- Contacts
- Facilities
- Facility Nodes
- Job Sites
- Projects
- Work Orders
- Tasks
- Issues
- Crews
- Equipment
- CRM Files

## Model relationship map

- `Account` has many `Contact`, `Facility`, `JobSite`, and `Project` records.
- `Contact` belongs to an `Account`.
- `Facility` belongs to an `Account`, and has many `FacilityNode`, `JobSite`, and `Project` records.
- `FacilityNode` belongs to a `Facility`, can belong to a parent `FacilityNode`, and can have child `FacilityNode` records.
- `JobSite` belongs to an `Account`, `Facility`, and optional `FacilityNode`; it has many `Project` records.
- `Project` belongs to an `Account`, optional `Facility`, optional `JobSite`, optional sales rep `User`, and optional project manager `User`; it has many `WorkOrder`, `Issue`, and `CrmFile` records.
- `WorkOrder` belongs to a `Project` and has many `Task` records.
- `Task` belongs to a `WorkOrder`, can belong to an assigned `User`, and has many `Issue` and `CrmFile` records.
- `Issue` belongs to a `Project`, optional `Task`, optional creator `User`, and optional assigned `User`; it has many `CrmFile` records.
- `Crew` has many `CrewMember` records.
- `CrewMember` belongs to a `Crew` and optional `User`.
- `Equipment` is currently standalone.
- `CrmFile` uses the `files` table and belongs to optional `Project`, `Task`, and `Issue` records.

## Notes

- Migrations assume PostgreSQL because the schema uses `pgcrypto`, `jsonb`, and GIN full-text indexes.
- UUIDs are generated by both Laravel models and the database default as a backup.
- `CrmFile` is used instead of `File` to avoid colliding with PHP/Laravel file classes.
