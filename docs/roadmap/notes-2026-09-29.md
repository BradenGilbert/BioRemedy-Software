## Owner decisions taken in the session (2026-09-29)

- **Facility relationships:** site parties (Owner / Tenant / Property manager / Other, with dates) on the facility, and a separate "Hired by" account on the project or dispatch.
- **Crew check-in:** build the driver's licence barcode scan now, not later.
- **Work Authorization:** we draft it from project and quote data; the owner reviews the wording before it goes live.
- **MSA:** once per account, with an expiry date.
